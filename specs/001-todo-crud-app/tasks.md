## 概要

このドキュメントは、バニラ HTML/CSS/JavaScript で実装する TODOアプリケーションの詳細実装タスク一覧です。

**アーキテクチャ**:
- フロントエンド: バニラ HTML5 + CSS3 + JavaScript（ES6）
- ストレージ: ブラウザ LocalStorage
- サーバー: なし（完全クライアント側実装）

**ファイル構成**:
```
index.html              # メイン HTML
css/style.css           # スタイル
js/
  ├── storage.js        # LocalStorage 管理モジュール
  ├── ui.js             # UI 操作・レンダリングモジュール
  └── app.js            # アプリケーションロジック + 初期化
```

## 備考

- すべてのタスクは `.` で始まる依存なしのステップを含めた
- 各ユーザーストーリーは独立してテスト可能（バックエンド実装不要）
- ブラウザの Developer Tools (F12) でローカルテスト可能
- LocalStorage は同一オリジンで共有されるため、複数タブでアプリを開くと同じデータを参照
