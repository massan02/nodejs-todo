# UI イベント仕様: TODOアプリケーション

**作成日**: 2025-10-22
**対象**: フロントエンド JavaScript UI

---

## UI 画面構成

### 画面 1: タスク一覧画面

ユーザーが最初に見る画面。すべてのタスクを表示。タスク作成、編集、削除のエントリーポイント。

**要素**:
- ヘッダー: "TODOアプリケーション"
- タスク一覧テーブル / リスト
  - 各行: タスク名 | 完了チェックボックス | 編集ボタン | 削除ボタン
- "新規タスク作成" ボタン

**イベント**:

| イベント | トリガー | 動作 |
|---------|--------|------|
| `load-tasks` | 画面起動時 | LocalStorage からタスク読み込み、一覧に表示 |
| `create-task-click` | "新規タスク作成" ボタン | タスク作成画面へナビゲート |
| `edit-task-click` | タスク行の "編集" ボタン | タスク編集画面へナビゲート（タスク ID 渡す） |
| `delete-task-click` | タスク行の "削除" ボタン | 削除確認モーダル表示 |
| `task-deleted` | 削除確認で "はい" | ストレージから削除、一覧更新 |
| `toggle-completed` | タスク行の チェックボックス | completed フラグ トグル、ストレージ更新 |

---

### 画面 2: タスク作成画面

新しいタスクを作成するためのフォーム画面。

**要素**:
- タイトル入力フィールド（テキスト）
- 説明入力フィールド（テキストエリア）
- "保存" ボタン
- "キャンセル" ボタン

**イベント**:

| イベント | トリガー | 動作 |
|---------|--------|------|
| `form-mount` | 画面遷移時 | フォーム初期化（フィールド空欄） |
| `title-change` | タイトルフィールド入力 | リアルタイム入力値保持 |
| `description-change` | 説明フィールド入力 | リアルタイム入力値保持 |
| `save-task-click` | "保存" ボタン | バリデーション実行 → 成功時：タスク作成 API 呼び出し |
| `save-success` | API 成功時 | ストレージ更新、一覧画面へナビゲート |
| `save-error` | API エラー時 | エラーメッセージ表示 |
| `cancel-click` | "キャンセル" ボタン | フォーム入力破棄、一覧画面へナビゲート |

---

### 画面 3: タスク編集画面

既存タスクを編集するためのフォーム画面。

**要素**:
- タイトル入力フィールド（既存値プリフィル）
- 説明入力フィールド（既存値プリフィル）
- 完了チェックボックス（既存値チェック）
- "保存" ボタン
- "削除" ボタン
- "キャンセル" ボタン

**イベント**:

| イベント | トリガー | 動作 |
|---------|--------|------|
| `form-mount` | 画面遷移時 | タスク ID から既存タスク取得、フォームに値をプリフィル |
| `title-change` | タイトルフィールド入力 | リアルタイム入力値保持 |
| `description-change` | 説明フィールド入力 | リアルタイム入力値保持 |
| `completed-toggle` | 完了チェックボックス | チェック状態トグル |
| `save-task-click` | "保存" ボタン | バリデーション → 更新 API 呼び出し |
| `update-success` | API 成功時 | ストレージ更新、詳細画面へナビゲート |
| `update-error` | API エラー時 | エラーメッセージ表示 |
| `delete-click` | "削除" ボタン | 削除確認モーダル表示 |
| `delete-confirmed` | 削除確認で "はい" | 削除 API 呼び出し → 一覧画面へ |
| `cancel-click` | "キャンセル" ボタン | フォーム入力破棄、詳細画面へ戻る |

---

### 画面 4: タスク詳細画面

選択したタスクの詳細情報を表示（編集しない読み取り専用）。

**要素**:
- タスク名（読み取り専用）
- タスク説明（読み取り専用）
- 完了ステータス（読み取り専用）
- 作成日時（読み取り専用）
- 最終更新日時（読み取り専用）
- "編集" ボタン
- "一覧へ戻る" ボタン

**イベント**:

| イベント | トリガー | 動作 |
|---------|--------|------|
| `detail-mount` | 画面遷移時 | タスク ID からタスク情報取得、表示 |
| `edit-click` | "編集" ボタン | タスク編集画面へナビゲート |
| `back-click` | "一覧へ戻る" ボタン | 一覧画面へナビゲート |

## ナビゲーション フロー

```
[タスク一覧] ← → [タスク作成]
    ↕           ↕
[タスク詳細] ← → [タスク編集]
```

### ナビゲーションルール

| 遷移元 | 遷移先 | トリガー |
|------|------|--------|
| 一覧 | 作成 | "新規タスク作成" ボタン |
| 一覧 | 詳細 | タスク名クリック |
| 一覧 | 編集 | "編集" ボタン（行内） |
| 作成 | 一覧 | "保存" または "キャンセル" |
| 詳細 | 一覧 | "一覧へ戻る" ボタン |
| 詳細 | 編集 | "編集" ボタン |
| 編集 | 詳細 | "保存" ボタン（成功時） |
| 編集 | 一覧 | "キャンセル" または "削除後" |

## バリデーションルール（クライアント側）

### タイトル

- 必須（空でない）
- 最小 1 文字、最大 100 文字
- エラー表示: "タイトルは 1～100文字で入力してください"

### 説明

- オプション（空可）
- 最大 500 文字
- エラー表示: "説明は 500文字以内で入力してください"

## ローカルストレージ管理

**Key**: `todo_app_tasks`

### 読み込み

```javascript
const tasks = JSON.parse(localStorage.getItem('todo_app_tasks') || '[]');
```

### 保存

```javascript
localStorage.setItem('todo_app_tasks', JSON.stringify(tasks));
```

### 削除

```javascript
localStorage.removeItem('todo_app_tasks');
```

## エラーハンドリング

### ネットワークエラー

API 呼び出し失敗時：
- エラーメッセージ表示: "データの保存に失敗しました。もう一度お試しください"
- ユーザー入力は保持（フォーム破棄しない）
- リトライボタン提供

### バリデーションエラー

入力エラー時：
- フィールド横に赤色エラーメッセージ表示
- 送信ボタン無効化（エラー解除まで）
- 複数エラー時はすべて表示

### LocalStorage 満杯

容量超過時：
- エラーメッセージ表示: "ブラウザの保存領域が満杯です。古いタスクを削除してください"
- ユーザー操作は続行可能（メモリに保持、永続化できない）

## アクセシビリティ

- キーボードナビゲーション対応（Tab キーでフォーカス移動）
- 入力フィールドに `label` タグ関連付け
- ボタンに `aria-label` 属性設定
- エラーメッセージは画面リーダーで読まれるよう `role="alert"` 使用
